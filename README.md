## ✨ 概要
「アイカツ！カードチェッカー」は、アイカツ！シリーズのカードをコレクション管理・交換管理するためのWebアプリです。  
ブラウザ上で動作するため、専用ソフトウェアのインストールは必要ありません。  
同梱のジェネレーターツールを使ってカードデータを生成・読み込むことで、自分の環境に合わせたカード一覧を作成し、所持状況や交換用データを管理できます。


### 主な用途
- カードの所持・未所持管理
- コレクションの進捗確認
- 欲しいカード（求）の管理
- 交換可能なカード（譲）の管理
- カードの検索・絞り込み
- 交換募集用画像の作成
- 交換募集文の作成
- データのバックアップ・復元

---

## 🚀 主な機能

### 📋 カードコレクション管理
カードごとに所持状況を管理できます。

所持 / 未所持

求（探しているカード） / 譲（交換に出せるカード）
などの状態を管理し、自分のコレクションを一覧で確認できます。

### 🔎 カード検索・絞り込み
大量のカードから目的のカードを簡単に探せます。  
カード番号、カード名、レアリティ、カテゴリなど、読み込んだカードデータに応じて検索・絞り込みを行えます。

### 📊 コレクション進捗
カードの所持状況を集計し、コレクションの進捗を確認できます。  
シリーズごとの管理にも対応できる構成になっています。

### 🔄 求・譲管理
交換を目的として、**求**（探しているカード）および**譲**（交換に出せるカード）をそれぞれ管理し、交換候補を整理できます。

### 🖼️ 交換募集画像の作成
登録した「求」「譲」のカード情報を利用して、SNS投稿用の交換募集画像を簡単に生成できます。

### 📝 交換募集文の作成
登録した交換情報をもとに、X（旧Twitter）等のSNSへ投稿するためのテキストを自動生成します。

⚙️ カードデータの一括生成（ジェネレーター）
Excelやスプレッドシート等で作成したCSVデータをドラッグ＆ドロップするだけで、アプリに読み込ませるためのデータファイル（cards_data.js および series_manifest.json）を自動生成する専用ツール（aikatsu_cards_data_generator.html）を搭載しています。

📦 カードデータの準備について
本リポジトリには、公式の画像URLやカード情報が記述された設定ファイルは（著作権への配慮から）直接組み込んでいません。

利用者は、自身で用意したリスト（ExcelファイルやCSV等）を用いてデータを作成します。同梱されている card_data.xlsx などを参考にリストを作成してください。

必須となるデータ列（CSV）
カードID (必須)
画像URL (必須)
カード名
レアリティ (ノーマル, プレミアムレア, レア,  キャンペーン 等)
タイプ (キュート, クール, セクシー, ポップ)
カテゴリ (トップス, ボトムス, シューズ, アクセサリー, トップス&ボトムス)

⚠️ 注意

本アプリは、第三者が提供するカードデータや画像の利用許諾を保証するものではありません。
画像の取得・利用については、各データの提供元が定める利用条件・権利表示等を確認し、私的利用の範囲で行ってください。

### 💾 データのバックアップ・復元
ブラウザに保存されている管理データをJSON形式でバックアップ・復元できます。
PCの変更やブラウザデータの消失に備えて定期的なバックアップをおすすめします。

### 🌙 ダークモード / 📱 レスポンシブ対応
画面テーマの切り替えに対応しているほか、PCだけでなくスマートフォンやタブレットでも快適に利用できます。

## 📦 カードデータについて
本リポジトリには、公式サイト等から取得したカードデータを同梱していません。  
以下のファイルは公開リポジトリから除外・削除しています。

- `cards_data.js`
- `series_manifest.json`

これは、公式サイトに掲載されている画像・テキスト・データ等を本リポジトリで再配布することを避けるためです。

### データの読み込み
本アプリでは、**利用者が自身で用意したカードデータを読み込んで利用する構成**を想定しています。  
カードデータの形式については、アプリ側で定義されたデータ仕様に従ってください。

> 本アプリは、第三者が提供するカードデータの利用許諾を保証するものではありません。データの取得・利用については、各データの提供元が定める利用条件・権利表示等を確認してください。

## 📖 使い方

Step 1: カードデータの生成
お手持ちのカードリスト（Excel等）から、card_data.xlsxに記載したカードデータを各シリーズごとにCSVファイルを出力します。

同梱の aikatsu_cards_data_generator.html をブラウザで開きます。

出力したCSVファイルをドラッグ＆ドロップして追加します。

シリーズIDや表示名、弾バッジ（例: 1弾）を設定し、「2ファイルを生成する」ボタンを押します。

生成された cards_data.js と series_manifest.json を保存（またはコピー）します。

Step 2: メインアプリでの利用
Step 1で作成したデータをindex.htmlと同じ階層に保存し、
index.html をブラウザで開きます。

カード一覧が表示されたら、所持状況や「求」「譲」の登録を開始します。
登録が完了したら、ツールバーから交換募集画像やテキストを出力してご活用ください。
※画像生成でカードが表示されない場合は再度画像生成をしてください。


## 💾 データの保存について
カードの管理情報は、利用者のブラウザ内（LocalStorage等）に保存されます。  

※ブラウザのデータ削除・キャッシュクリア・端末変更によって保存データが失われる可能性があります。
重要なデータは、バックアップ機能を利用して定期的に保存してください。
